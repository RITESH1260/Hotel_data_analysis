# 🏨 Hotel Data Analysis

A data analysis project focused on exploring and analyzing hotel booking data using **Python, Pandas, NumPy, Matplotlib, and Jupyter Notebook**.

The project organizes the raw data and analysis notebooks separately to make the workflow easy to understand and reproduce.

## 📌 Project Overview

This project analyzes hotel booking data to discover useful patterns and insights related to:

- 📅 Booking trends over time
- 🏨 Hotel and district-wise bookings
- 📍 Location-based analysis
- 🕐 Average check-in and check-out times
- 📊 Booking distribution by date and district
- 💰 Revenue and other business-related metrics
- 🔎 Data cleaning and exploratory data analysis (EDA)

## 🔍 Analysis Workflow

The project follows a typical data-analysis workflow:

1. **Load the dataset**
2. **Understand the data**
3. **Clean missing and inconsistent values**
4. **Transform columns where required**
5. **Perform Exploratory Data Analysis (EDA)**
6. **Calculate statistics and business metrics**
7. **Analyze data by date, district, and other categories**
8. **Create visualizations**
9. **Extract meaningful insights**

## 📈 Key Analysis Areas

### District-wise Analysis
Analyze hotel bookings according to different districts and compare booking volumes between locations.

### Date-wise Booking Analysis
Identify how many bookings were made for each date and understand booking patterns over time.

### Check-in & Check-out Analysis
Calculate and compare average check-in and check-out times to understand customer arrival and departure behavior.

### Exploratory Data Analysis
Use statistical summaries and visualizations to identify trends, distributions, relationships, and unusual values in the dataset.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/RITESH1260/Hotel_data_analysis.git
```

### 2. Open the project

```bash
cd Hotel_data_analysis
```

### 3. Install the required libraries

```bash
pip install pandas numpy matplotlib jupyter
```

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

Open the notebooks inside the `Notebook` folder and run the cells in order.
